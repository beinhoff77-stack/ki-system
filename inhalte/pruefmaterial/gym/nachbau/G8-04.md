## Lösungsblatt G8-04

**1a** (3 P) – Ergebnis: 2(x − 3) / x
- mit dem Kehrwert multiplizieren (1 P)
- x² − 9 = (x − 3)(x + 3) (1 P)
- kürzen → 2(x − 3)/x (x ≠ 0, x ≠ −3) (1 P)
- *Zuordnung: terme.bruchterme › multiplizieren (Bruchterme multiplizieren und dividieren); Niveau II, K5*

**1b** (4 P) – Ergebnis: 8 / (x² − 16)
- Hauptnenner (x − 4)(x + 4) = x² − 16 (1 P)
- Zähler: (x + 4) − (x − 4) = 8 (1 P)
- Ergebnis 8/(x² − 16), x ≠ ±4 (2 P)
- *Zuordnung: terme.bruchterme › addieren (Bruchterme addieren und subtrahieren); Niveau III, K5*

**1c** (3 P) – Ergebnis: 6 / (x² − 9)
- Hauptnenner (x − 3)(x + 3) = x² − 9 (1 P)
- Zähler: (x + 3) − (x − 3) = 6 (1 P)
- Ergebnis 6/(x² − 9), x ≠ ±3 (1 P)
- *Zuordnung: terme.bruchterme › addieren (Bruchterme addieren und subtrahieren); Niveau II, K5*

**2a** (3 P) – Ergebnis: D = ℚ \ {−5; −3}; x = −1
- Hauptnenner (x + 5)(x + 3) · −4(x + 3) = −2(x + 5) (1 P)
- −2x = 2 → x = −1 (1 P)
- x liegt in D (1 P)
- *Zuordnung: gleichungen.bruch › hauptnenner (Mit dem Hauptnenner multiplizieren); Niveau II, K5*

**2b** (3 P) – Ergebnis: D = ℚ \ {2; −4}; x = 9
- Hauptnenner (x + (−2))(x + 4) · 14(x + 4) = 26(x + (−2)) (1 P)
- −12x = −108 → x = 9 (1 P)
- x liegt in D (1 P)
- *Zuordnung: gleichungen.bruch › hauptnenner (Mit dem Hauptnenner multiplizieren); Niveau II, K5*

**2c** (4 P) – Ergebnis: D = ℚ \ {−6; 6}; x = 3
- x² − 36 = (x − 6)(x + 6) ist Hauptnenner (1 P)
- (x + 6) + (x − 6) = 6 (1 P)
- 2x = 6 → x = 3 ∈ D (2 P)
- *Zuordnung: gleichungen.bruch › hauptnenner (Mit dem Hauptnenner multiplizieren); Niveau III, K5*

**2d** (4 P) – Ergebnis: L = { }
- D = ℚ \ {4} (1 P)
- mal (x − 4): x = 4 (1 P)
- 4 ∉ D → keine Lösung (2 P)
- *Zuordnung: gleichungen.bruch › scheinloesung (Lösung prüfen: Gehört sie zu D?); Niveau III, K5*

**3** (4 P) – Ergebnis: (3 + x)/(14 + x) = 9/20; x = 6
- (3 + x)·20 = 9·(14 + x) (2 P)
- x = 6 (2 P)
- *Zuordnung: Lücke – Vorschlag „Bruchgleichung aus einem Text über Zähler und Nenner aufstellen“ (gleichungen.bruch); Niveau III, K3*
