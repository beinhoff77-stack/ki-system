Mathe-Merkblatt Klasse 7/8

Alles, was beim Lösen von Gleichungen immer wieder gebraucht wird, auf einer Seite: Zahlen, Terme, Potenzen, Brüche, Gleichungen und Gleichungssysteme mit zwei Unbekannten. Die Beispiele sind Schritt für Schritt vorgerechnet und lassen sich selbst durchspielen.

Kästchen mit dem Hinweis „oft erst Kl. 8/9“ gehen über den Standardstoff der Klasse 7/8 hinaus. Was wann drankommt, hängt vom Bundesland und vom Schulbuch ab.

So liest du die Rechenwege

3x + 4 = 19
3x = 15| − 4
x = 5| : 3

Links steht die Gleichung nach dem Schritt. Rechts hinter dem Strich steht, was auf beiden Seiten getan wurde.

Zahlen

Vorzeichen, Rechenreihenfolge und Teilbarkeit. Das Fundament für alles Weitere.

Zahlenmengen

ℕ natürliche Zahlen: 1, 2, 3, … (je nach Buch mit 0)
ℕ ⊂ ℤ ⊂ ℚ
ℤ ganze Zahlen: … −2, −1, 0, 1, 2 …
ℚ rationale Zahlen: alle Brüche, auch Dezimalzahlen
0,75 = 34   13 = 0,333…
Bruch → Dezimalzahl: Zähler : Nenner
38 = 3 : 8 = 0,375
Dezimalzahl → Bruch: Stellen zählen
0,35 = 35100 = 720

Vorzeichen (Plus / Minus)

Mal und geteilt: gleiche Vorzeichen → +, verschiedene → −
(−3)·(−4) = 12
(−12) : 4 = −3
Plus: gleiche Vorzeichen: Beträge addieren, Vorzeichen bleibt
−3 + (−4) = −7
Plus: verschiedene Vorzeichen: Beträge subtrahieren, Vorzeichen der größeren Zahl
−3 + 8 = 5
3 + (−8) = −5
Minus minus = plus: Subtrahieren heißt Gegenzahl addieren
5 − (−2) = 5 + 2 = 7

1. Klammern · 2. Potenzen · 3. Punkt (· :) vor Strich (+ −) · 4. von links nach rechts
Ohne Klammer

Mit Klammer
(2 + 3)·42 = 5·16 = 80

durch 9: Quersumme durch 9 teilbar

Terme

Zusammenfassen, Klammern auflösen, binomische Formeln.

Zusammenfassen und Klammern

Nur Gleichartiges zusammenfassen: x-Terme mit x-Termen

Plus vor Klammer: weglassen

Minus vor Klammer: alle Vorzeichen drehen

Zahl vor Klammer: mal jedes Glied
−2(x − 3) = −2x + 6
Klammer mal Klammer: jedes mit jedem

Brüche

Erweitern, Kürzen, Rechnen und der Kehrwert (Umkehrbruch).

Brüche: Begriffe

Zähler / Nenner. Der Nenner darf nie 0 sein.
34: Zähler 3, Nenner 4
Ganze Zahl als Bruch
3 = 31
Gemischte Zahl: Ganze · Nenner + Zähler
213 = 2·3+13 = 73
Kehrwert (Umkehrbruch): Zähler und Nenner tauschen
34 → 43   5 → 15
x3 → 3x

Erweitern und Kürzen

Erweitern: Zähler und Nenner mit derselben Zahl mal
23 = 69  (· 3)
Kürzen: Zähler und Nenner durch dieselbe Zahl teilen
1218 = 23  (: 6)
Gekürzt wird nur Faktor mit Faktor, nie Summen. Erst ausklammern.
2x+62 = 2(x+3)2 = x + 3

Rechnen mit Brüchen

Plus / Minus: gleichnamig machen (Hauptnenner), Nenner bleibt, nur Zähler rechnen
12 + 13 = 36 + 26 = 56
Mal: Zähler·Zähler, Nenner·Nenner (vorher kürzen)
23·45 = 815
34·29 = 16
Geteilt: mit dem Kehrwert multiplizieren
23 : 45 = 23·54 = 56
Bruch mal / geteilt durch ganze Zahl
3·25 = 65   23 : 4 = 16
Doppelbruch: oberer Bruch mal Kehrwert des unteren
(3/4) : (9/8) = 34·89 = 23

Gleichnamig machen wie bei Zahlen

Summe im Zähler darf man aufteilen

Gleichungen

Eine Gleichung ist wie eine Waage im Gleichgewicht: Was du links tust, tust du rechts auch.

Die Waage: auf beiden Seiten dasselbe

Start: links 3x + 4, rechts 19

Jeder Schritt tut links und rechts genau dasselbe. Darum bleibt die Waage im Gleichgewicht und die Lösung ändert sich nicht.

Das Rezept in 5 Schritten

Goldene Regel: auf beiden Seiten dasselbe tun. Umkehren: + ↔ −, · ↔ :. Nie mit 0 mal, nie durch 0.
1. Vereinfachen (Klammern, Brüche weg, zusammenfassen)
3(x−2) + 4 = 3x − 2
2. x auf eine Seite bringen
| − 2x
3. Zahlen auf die andere Seite bringen
| + 2
4. Durch die Zahl vor x teilen, mit Vorzeichen
−4x = 28  | : (−4)
x = −7
5. Probe in der Ausgangsgleichung
x einsetzen: links = rechts?

Sonderfälle und Umstellen

x fällt weg: wahr → L = ℚ · falsch → L = { }
6 = 6 → ℚ
1 = 5 → { }
Formel umstellen wie eine Gleichung
U = 2(a+b) → b = U2 − a
Nach x auflösen (a ≠ c)
ax + b = cx + d
x = d−ba−c

Gleichungssysteme

Zwei Gleichungen, zwei Unbekannte: vier Verfahren und ein Graph, der die Lösung zeigt.

Die Idee

oft erst Kl. 8/9
Zwei Unbekannte (x und y) brauchen zwei Gleichungen. Gesucht ist das Paar (x | y), das beide erfüllt.
1. Eine Unbekannte verschwinden lassen
übrig bleibt eine Gleichung mit einer Unbekannten
2. Die zweite Unbekannte durch Einsetzen berechnen
Ergebnis als Paar (x | y)
3. Probe in beiden Gleichungen
sonst ist die Probe nicht vollständig

Welches Verfahren?

Eine Gleichung ist schon nach x oder y aufgelöst
y = x + 3 → Einsetzen
Beide Gleichungen sind nach derselben Variablen aufgelöst
y = … und y = … → Gleichsetzen
Gleiche Zahl bei x oder y, aber mit Gegenvorzeichen
+2y und −2y → Addition
Sonst: Gleichung(en) mit einer Zahl multiplizieren
I · 3 und II · (−2), dann Addition

Graph: Wo schneiden sich die Geraden?

Jede Gleichung ist eine Gerade. Die Lösung ist der Punkt, in dem sich beide Geraden treffen. Ändere die Zahlen oder nimm ein Beispiel.

Einsetzen

Wenn eine Gleichung schon nach x oder y aufgelöst ist.
I: y = x + 3   II: 2x + y = 18
2x + (x + 3) = 18| y durch x + 3 ersetzen
3x + 3 = 18zusammenfassen
3x = 15| − 3
x = 5| : 3
y = 5 + 3 = 8x in I einsetzen
(x | y) = (5 | 8)
Probe: I: 8 = 5 + 3 ✓ · II: 2·5 + 8 = 18 ✓

Gleichsetzen

Wenn beide Gleichungen nach derselben Variablen aufgelöst sind.
I: y = 2x − 1   II: y = x + 4
2x − 1 = x + 4beide y-Terme gleichsetzen
x − 1 = 4| − x
x = 5| + 1
y = 5 + 4 = 9x in II einsetzen
(x | y) = (5 | 9)
Probe: I: 2·5 − 1 = 9 ✓ · II: 5 + 4 = 9 ✓

Addition

Wenn bei x oder y dieselbe Zahl mit Gegenvorzeichen steht.
I: 3x + 2y = 13   II: 5x − 2y = 11
8x = 24I + II (+2y und −2y fallen weg)
x = 3| : 8
3·3 + 2y = 13x in I einsetzen
2y = 4| − 9
y = 2| : 2
(x | y) = (3 | 2)
Probe: I: 9 + 4 = 13 ✓ · II: 15 − 4 = 11 ✓

Addition mit Vorbereitung

Wenn keine Variable passt: erst mit Zahlen multiplizieren, beide Seiten der Gleichung.
I: 2x + 3y = 13   II: 3x + 2y = 12x soll wegfallen
6x + 9y = 39I · 3
−6x − 4y = −24II · (−2)
5y = 15beide addieren
y = 3| : 5
2x + 3·3 = 13y in I einsetzen
x = 2| − 9 und : 2
(x | y) = (2 | 3)
Probe: I: 4 + 9 = 13 ✓ · II: 6 + 6 = 12 ✓

Typische Fehler

Diese Fehler schleichen sich immer wieder ein. Links der Fehler, rechts die richtige Lösung.

Potenzen

✗ 23·24 = 212
✓ 23·24 = 27

Beim Malnehmen werden die Exponenten addiert.

✗ a2 + a3 = a5
✓ bleibt a2 + a3

Nur gleichartige Terme fasst man zusammen: 3a2 + 2a2 = 5a2.

✗ (a + b)2 = a2 + b2
✓ (a + b)2 = a2 + 2ab + b2

Das mittlere Glied 2ab fehlt sonst.

✗ 2·32 = 62 = 36
✓ 2·32 = 2·9 = 18

Erst die Potenz, dann das Malnehmen.

✗ −32 = 9
✓ −32 = −9   (−3)2 = 9

Ohne Klammer gehört das Minus nicht zur Basis.

Brüche

✗ x+33 = x + 1
✓ x+33 = x3 + 1

Gekürzt werden nur Faktoren, nie Summanden.

✗ 12 + 13 = 25
✓ 12 + 13 = 56

Hauptnenner suchen. Die Nenner werden nicht addiert.

✗ 23 : 45 = 23·45
✓ 23 : 45 = 23·54

Beim Teilen wird mit dem Kehrwert multipliziert.

✗ Erweitern nur im Zähler
✓ Zähler und Nenner mit derselben Zahl

Sonst ändert sich der Wert des Bruchs.

✗ −x−22 = −x−22
✓ −x−22 = −x+22

Das Minus dreht alle Vorzeichen im Zähler um.

Gleichungen

✗ −(x − 3) = −x − 3
✓ −(x − 3) = −x + 3

Minus vor der Klammer: alle Vorzeichen drehen.

✗ 2(x + 3) = 2x + 3
✓ 2(x + 3) = 2x + 6

Die Zahl vor der Klammer mal jedes Glied.

✗ −4x = 28 → x = 7
✓ −4x = 28 → x = −7

Durch −4 teilen, nicht durch 4.

✗ 2x + 6 = 10  | − 6 nur links
✓ 2x + 6 = 10  | − 6 auf beiden Seiten

Die goldene Regel: beide Seiten.

✗ 3 + 2x = 5x
✓ 3 + 2x bleibt 3 + 2x

Zahl und x-Term sind nicht gleichartig.

✗ x2 + 1 = 4  | · 2 → x + 1 = 8
✓ x2 + 1 = 4  | · 2 → x + 2 = 8

Beim Hauptnenner auch die Zahl ohne Bruch mal nehmen.

Gleichungssysteme

✗ Nur x ausrechnen und aufhören
✓ x und y berechnen, Ergebnis als Paar (x | y)

Die Lösung besteht immer aus zwei Zahlen.

✗ Probe nur in einer Gleichung
✓ Probe in beiden Gleichungen

Ein Paar muss beide Gleichungen erfüllen.

✗ 2x + 3y = 13  | · 3 → 6x + 9y = 13
✓ 2x + 3y = 13  | · 3 → 6x + 9y = 39

Beim Multiplizieren die ganze Gleichung nehmen, auch die rechte Seite.
